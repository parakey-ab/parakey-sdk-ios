# ParakeySDK

## Documentation

Documentation can be found [here](https://parakey-ab.github.io/parakey-sdk-ios/documentation/parakeysdk/)

## Installation

### SPM

In Xcode, go to **File** → **Add Packages Dependencies** and enter the repository URL:

```
https://github.com/parakey-ab/parakey-sdk-ios.git
```

Set **Dependency Rule** to **Exact Version** and enter the latest release tag (currently `2.7.1`).

### CocoaPods

[CocoaPods](https://cocoapods.org) is a dependency manager for Cocoa projects. For usage and installation instructions, visit their website. To integrate the Parakey SDK into your Xcode project using CocoaPods, specify it in your `Podfile`:

```ruby
pod 'ParakeySDK', :git => 'git@github.com:parakey-ab/parakey-sdk-ios.git', :tag => '2.7.1'
```
